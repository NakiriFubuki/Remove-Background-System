## 🚀 How to Contribute

1. **Fork the repository** 📚
2. **Clone your fork**
   ```bash
   git clone https://github.com/NakiriFubuki/Remove-Background-System.git
   ```
3. **Navigate into the project directory**
   ```bash
   cd Remove-Background-System
   ```
4. **Create a new branch** 🌿
   ```bash
   git checkout -b feature/your-feature-name
   ```
5. **Run the project locally with XAMPP**
   - Copy / open the project under `C:\xampp\htdocs\Remove Background System`
   - Start **Apache** (and **MySQL** if you need Recent Results)
   - Optional: import `database/schema.sql` via phpMyAdmin
   - Visit `http://localhost/Remove%20Background%20System/`
6. **Make your changes** ✨
7. **Test your changes**
   - Upload a JPG / PNG / WEBP image
   - Click **Remove Background** and confirm the transparent preview
   - Test **Download PNG** and **Reset**
   - Open the **User Manual** from the top navigation
8. **Commit your changes** 💾
   ```bash
   git commit -m "Add: a meaningful commit message"
   ```
9. **Push to your branch** 📤
   ```bash
   git push origin feature/your-feature-name
   ```
10. **Create a Pull Request** 🛠️

## 📋 Contribution Guidelines

- 🎨 Keep the UI clean, modern, and consistent with the existing dark teal design
- 🧹 Follow existing naming conventions and file structure
- 🔐 Use prepared statements for any new SQL
- 🛡️ Sanitize output to prevent XSS
- 💬 Write clear, concise commit messages
- 📝 Update the User Manual / README when you change user-facing behavior
- 🔒 Do not commit secrets, credentials, or uploaded / processed images

---

## ✅ Pull Request Process

- Create PRs from a feature branch (not directly from `main`)
- Describe **what** changed and **why**
- Include screenshots for UI changes when possible
- Wait for review / approval before merging

---

## 🐛 Reporting Issues

Found a bug or have a feature idea? Please open an Issue and include:

- 🖥️ Browser / OS information
- 🔁 Steps to reproduce
- ✅ Expected vs actual result
- 🖼️ Screenshots (if UI-related)
